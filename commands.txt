1. Make the global path


ros2 launch rover_nav nav2_planning.launch.py rviz:=true
ros2 run rover_nav plan_global_path.py --start S1 --points W7 W4 W9 W8 --loop --publish



2. Run the rover WITH ArUco marker correction


ros2 launch aries_bringup full_hardware.launch.py \
  path_csv:=$HOME/jazzy_ws/marsyard/global_path_hybrid.csv \
  waypoints_csv:=$HOME/jazzy_ws/marsyard/global_path_hybrid_waypoints.csv \
  map_to_odom_yaw_deg:=90 \
  enable_front_camera:=true front_camera_serial:=<serial> \
  start_aruco:=true aruco_snap:=true
  

4. Run the rover WITHOUT ArUco marker correction


ros2 launch aries_bringup full_hardware.launch.py \
  path_csv:=$HOME/jazzy_ws/marsyard/global_path_hybrid.csv \
  waypoints_csv:=$HOME/jazzy_ws/marsyard/global_path_hybrid_waypoints.csv \
  map_to_odom_yaw_deg:=90 \
  lookahead_dynamic:=false \
  lookahead_distance:=0.5 

6. Lookahead distance — dynamic vs. fixed
Add these to any launch command above:


lookahead_dynamic:=false lookahead_distance:=0.5     # fixed 0.5 m (current default)
lookahead_dynamic:=true                              # dynamic (auto-adjusts 0.4–0.7 m)



drawing the global path 

Draw → refine → drive
```
ros2 launch rover_nav nav2_planning.launch.py rviz:=true
ros2 run rover_nav draw_path.py
```
In RViz, use the Publish Point tool (already in nav2_path_view.rviz's toolbar) and click a rough route across the map, in order. A yellow line + orange dots track your clicks live on /draw_path/preview (already displayed).
Refine it through the same costmap-aware, curvature-bounded Hybrid-A* planner as everything else:
```
ros2 service call /draw_path/refine std_srvs/srv/Trigger
```
This feeds your clicks to plan_global_path.py as an ordered point list and republishes the result on /pure_pursuit/path so you see the refined version immediately.
Not happy with it? ```ros2 service call /draw_path/clear std_srvs/srv/Trigger``` and redraw.
Happy? Drive it — the service response prints the exact command, or:

```
ros2 launch aries_bringup full_hardware.launch.py \
  path_csv:=$HOME/jazzy_ws/marsyard/drawn_path.csv \
  waypoints_csv:=$HOME/jazzy_ws/marsyard/drawn_path_waypoints.csv

  ```
